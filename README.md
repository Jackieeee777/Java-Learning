**Main Project: Student Score Statistics**

File: `DAY03ScoresStatistics.java`

**Project Description:**

A simple Java program that stores student scores in an array and calculates basic statistics.

**Features:**
- Store multiple student scores in an integer array
- Calculate the total score using a for loop
- Calculate the average score using type casting
- Find the highest score using conditional statements
- Display the statistical results

**Example Code:**

```java
int[] scores = {85, 92, 76, 88, 95};

int sum = 0;

for (int i = 0; i < scores.length; i++) {
    sum += scores[i];
}

double average = (double) sum / scores.length;

int max = scores[0];

for (int i = 1; i < scores.length; i++) {
    if (scores[i] > max) {
        max = scores[i];
    }
}
```

**Example Output:**

```text
Total Score:436
Average Score:87.2
Highest Score:95
```

**Key Takeaways:**
- Arrays can store multiple values of the same type.
- Array indexes start from 0.
- The length property provides the number of elements.
- For loops can efficiently process array elements.
- Type casting helps avoid integer division issues.
- Conditional statements can be used to find maximum values.
